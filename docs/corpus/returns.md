# Politique de retours / Returns Policy

## 1. Délai de retour / Return Window

Les clients peuvent retourner un article dans les **14 jours** suivant la réception, à condition qu'il soit **non utilisé** et dans son emballage d'origine.

Customers may return an item within **14 days** of receipt, provided it is **unused** and in its original packaging.

## 2. Articles non retournables / Non-returnable Items

Les articles suivants **ne peuvent pas** être retournés :
- Produits alimentaires ouverts
- Produits périssables
- Cartes-cadeaux
- Articles personnalisés

## 3. Procédure de retour / Return Process

1. Connectez-vous à votre compte.
2. Sélectionnez la commande et l'article à retourner.
3. Imprimez l'étiquette de retour prépayée.
4. Déposez le colis au point de collecte le plus proche.

## 4. Remboursement / Refund

Le remboursement est effectué sur le mode de paiement original dans les **5 à 7 jours ouvrables** après réception du retour.

## 5. Articles défectueux / Defective Items

Si un article est arrivé endommagé ou défectueux, contactez-nous dans les **48 heures** à returns@borealmarche.ca. Nous remplacerons l'article gratuitement.

## 6. Retours en magasin / In-store Returns

Les articles peuvent également être retournés dans nos points de retrait participants.
## 7. Articles en solde / Sale Items
Les articles achetés en solde (réduction de 50% ou plus) ne sont pas admissibles à un remboursement, mais peuvent être échangés contre un crédit en magasin dans les 14 jours.
## 8. Produits électroniques / Electronics
Les articles électroniques (thermomètres, balances de cuisine) doivent être retournés non ouverts. Si l'emballage est scellé par le fabricant et a été ouvert, des frais de restocking de 15% s'appliquent.
## 9. Retours pendant les fêtes / Holiday Returns
Pour les achats effectués entre le 1er novembre et le 24 décembre, la période de retour est prolongée jusqu'au 15 janvier de l'année suivante, sur présentation du reçu original.
