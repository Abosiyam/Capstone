# Politique de confidentialité / Privacy Policy

## 1. Données collectées / Data Collected

Boréal Marché collecte :
- Nom, adresse, courriel, téléphone
- Historique de commandes
- Préférences alimentaires
- Données de navigation

## 2. Utilisation des données / Use of Data

Les données sont utilisées pour :
- Traiter les commandes
- Personnaliser les recommandations
- Envoyer des offres promotionnelles
- Améliorer le service

## 3. Partage des données / Data Sharing

Nous ne vendons **jamais** vos données. Nous les partageons uniquement avec :
- Nos partenaires de livraison
- Nos processeurs de paiement
- Les autorités si requis par la loi

## 4. Vos droits (Loi 25) / Your Rights (Law 25)

Vous avez le droit de :
- Accéder à vos données
- Demander la correction
- Demander la suppression
- Refuser la personnalisation
- Demander une révision humaine d'une décision automatisée

## 5. Sécurité / Security

Les données sont chiffrées en transit et au repos.

## 6. Contact / Contact

Pour exercer vos droits : privacy@borealmarche.ca

## 7. Décisions automatisées / Automated Decisions

Notre système utilise l'IA pour :
- Prédire la fidélité des clients
- Recommander des produits
- Répondre aux questions

Ces décisions sont **révisées par un humain** avant toute action.
